# Conversor de temperaturas

Programa en Python que convierte temperaturas entre Celsius, Fahrenheit y Kelvin.

## Requisitos

- Python 3.8 o superior
- MkDocs (solo para generar la documentación)

## Arranque rápido

````bash
python conversor.py
````

## Documentación

La documentación completa está en la carpeta `docs/` y se genera con MkDocs:

````bash
pip install mkdocs
mkdocs serve
````
