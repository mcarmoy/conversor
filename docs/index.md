# Conversor de temperaturas

Esta aplicación es un programa de consola escrito en Python que convierte
temperaturas entre tres unidades:

| Unidad | Símbolo |
|--------|---------|
| Celsius | C |
| Fahrenheit | F |
| Kelvin | K |

## ¿Qué hace?

1. Pide una temperatura.
2. Pide la unidad de origen y la de destino.
3. Muestra el resultado de la conversión con dos decimales.
